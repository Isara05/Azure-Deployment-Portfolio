# Azure Deployment Portfolio ☁️

**Azure App Service · ASP.NET Core (.NET 8) · PHP · Application Insights**

A practical cloud deployment portfolio for **SWE40006 — Software Deployment and Evolution** at Swinburne University of Technology.

## Overview
This academic portfolio covers deploying, configuring, operating, and monitoring applications on Microsoft Azure.

## Project highlights
- Published a sample web application to Azure App Service and verified stop/start operations.
- Developed and deployed **IsaraTaskManagerWeb**, an ASP.NET Core MVC application with CRUD features.
- Explored application settings, environment variables, and Azure Log Stream diagnostics.
- Deployed a PHP application and tested telemetry using **Application Insights**.

## Skills demonstrated
| Area | Experience |
| --- | --- |
| Cloud hosting | Azure App Service |
| Application development | ASP.NET Core MVC, .NET 8, PHP |
| Deployment operations | Publishing, starting and stopping services, configuration |
| Observability | Log Stream, Application Insights |

## Notes
This is an academic deployment portfolio. Cloud resources used for coursework may be stopped, so a live demo is not guaranteed. Screenshots and supporting evidence should be reviewed alongside the application files where available.

**Security:** Do not commit Azure credentials, publish profiles, connection strings, or other secrets.
